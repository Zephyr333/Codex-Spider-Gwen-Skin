# 视觉规则与维护边界

本规则用于完整增强版 2.1.2。社区基础主题独立维护；完整增强版与社区基础版的版本号不能直接比较。

## 边缘层次

| 用途 | 外观 | 原因 |
| --- | --- | --- |
| 输入框 | 青色左下到粉色右上的连续渐变细边，输入聚焦时加强 | 标明当前输入区域 |
| 工具标题 | 同方向的低强度青粉双向内细边 | 保持展开入口可发现，避免每条记录发亮 |
| 工具输出、代码、文件卡片、提示、菜单 | 共用低强度青粉双向内细边与深色底 | 同类卡片不再混用纯蓝外框；不增加外框尺寸或伪元素 |
| 右侧摘要 | 同方向的柔和青紫粉渐变细边，仅由外壳绘制 | 避免内部 sticky 标题或列表重复画边 |
| 原生内部区隔 | 低对比度中性分隔线 | 分隔内容，不作为主题装饰 |
| 键盘焦点 | 清晰的青色轮廓 | 它是交互状态提示，不能为装饰一致性而隐藏 |
| 原生警告、错误、选中状态 | 保留状态含义 | 不将状态色强行改成装饰边框 |

青粉方向一致，不代表所有控件必须同样明亮。`--sg-card-edge`、`--sg-card-edge-soft` 与 `--sg-panel-edge` 集中管理卡片边缘；`--sg-focus-ring-both` 管理输入框渐变。

## 结构与性能

一个逻辑卡片只由一个外壳承担材质。内部文字、图标、代码、文件行不重复增加背景、模糊或边缘。不要为未知圆角或背景类名套统一材质。

装饰不得改变原生尺寸、事件、滚动、ARIA 和键盘操作。输入框溢出只在经过几何确认的装饰扩展期间调整；原生层中途接管写入时，皮肤停止竞争，不恢复陈旧值。

视觉修改优先使用 CSS，不新增轮询、全量扫描、图片滤镜或持续动画。卡片细边使用内阴影，不增加节点或覆盖原生伪元素。完整检查、原生操作与长期使用应分别验收。
