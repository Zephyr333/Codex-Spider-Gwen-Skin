# 视觉规则与维护边界

本规则用于完整增强版 2.1.3。社区基础主题独立维护；完整增强版与社区基础版的版本号不能直接比较。

## 边缘层次

| 用途 | 外观 | 原因 |
| --- | --- | --- |
| 输入框 | 左青、右粉的横向连续渐变细边，输入聚焦时加强 | 标明当前输入区域 |
| 工具标题 | 与输入框相同的横向连续青粉渐变 | 保持展开入口可发现 |
| 工具输出、代码、文件卡片、提示、菜单 | 与输入框相同的连续青粉渐变细边与深色底 | 同类卡片共用一种渐变，不增加外框尺寸 |
| 右侧摘要 | 同方向的柔和青紫粉渐变细边，仅由外壳绘制 | 避免内部 sticky 标题或列表重复画边 |
| 原生内部区隔 | 低对比度中性分隔线 | 分隔内容，不作为主题装饰 |
| 键盘焦点 | 清晰的青色轮廓 | 它是交互状态提示，不能为装饰一致性而隐藏 |
| 原生警告、错误、选中状态 | 保留状态含义 | 不将状态色强行改成装饰边框 |

所有装饰边框共用 `--sg-focus-ring-both` 的 90° 横向渐变，常态透明度统一为 .65；头像菜单、摘要、卡片与 Codex++ 入口均遵守该规则。45° 渐变在不同宽高比下会让方形容器的左上、右下偏紫，因此不再用于这些外框。圆角仍按组件用途保留，输入框聚焦时加强到 1。

## 结构与性能

一个逻辑卡片只由一个外壳承担材质。内部文字、图标、代码、文件行不重复增加背景、模糊或边缘。不要为未知圆角或背景类名套统一材质。

装饰不得改变原生尺寸、事件、滚动、ARIA 和键盘操作。输入框溢出只在经过几何确认的装饰扩展期间调整；原生层中途接管写入时，皮肤停止竞争，不恢复陈旧值。

视觉修改优先使用 CSS，不新增轮询、全量扫描、图片滤镜或持续动画。已识别外壳通过遮罩后的非交互伪元素绘制 1px 连续边缘，不新增节点，内部行和图标不重复绘制。定位默认规则使用零权重选择器，保留原生 sticky/absolute/fixed 定位。完整检查、原生操作与长期使用应分别验收。
